# Apuntes de clase

Un archivo por unidad o fecha de clase:

```
apuntes-clase/
└── AAAA-MM-DD-tema.md
```

En cada uno conviene anotar:

- Tema visto y qué definiciones dio el/la docente.
- Diferencias con lo que veníamos haciendo en el proyecto.
- Consignas o ejercicios indicados.
- Dudas que quedaron (y luego pasarlas a `apuntes/dudas-para-clase.md`).
