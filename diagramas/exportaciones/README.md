# exportaciones/ — PNG de los diagramas

Imágenes exportadas desde draw.io para incrustar en los documentos Markdown.

- Mismo nombre base que su fuente en `../drawio/`.
- Exportar a PNG con escala 2x (se ve nítido en PDF e informes).
- Si se actualiza el `.drawio`, **volver a exportar** el PNG (si no, el documento
  muestra una versión vieja del diagrama).
