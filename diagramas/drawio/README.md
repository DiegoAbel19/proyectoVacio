# drawio/ — fuentes editables

Aquí van los archivos `.drawio` del proyecto.

- Formato de archivo: `diagramas/drawio/<nomenclatura>.drawio`
  (ver tabla de nomenclatura en `docs/plantillas/plantilla-diagrama-drawio.md`).
- Al modificar un diagrama, reexportar el PNG en `../exportaciones/`.
- Este `.gitignore` excluye los backups (`*.drawio.bak`) de draw.io.
