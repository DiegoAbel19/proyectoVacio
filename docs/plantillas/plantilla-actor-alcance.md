## 1. Actores

Un **actor** es un rol (persona u otro sistema) que interactúa con el sistema
para alcanzar una meta. No es un usuario concreto: es el rol que desempeña.

| ID | Actor | Rol / Meta | Tipo | Justificación (¿por qué existe?) |
|----|-------|-----------|------|----------------------------------|
| AC-01 | | Principal / Secundario | Humano / Sistema | |
| AC-02 | | | | |

**Regla:** si un actor no participa en ningún caso de uso, sobra.
