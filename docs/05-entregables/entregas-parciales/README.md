# Entregas parciales

Trabajos por unidad o fecha de entrega de la cátedra.

## Convención de carpetas

Una carpeta por entrega, nombrada con fecha y tema:

```
entregas-parciales/
└── AAAA-MM-DD-tema/
    ├── README.md        # qué entrega, criterios y estado
    └── <documento>.md   # el entregable en sí
```
