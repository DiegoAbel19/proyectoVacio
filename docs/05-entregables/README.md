# Fase 5 — Entregables

Documentos finales que se presentan en la materia: informes, evaluaciones y
cualquier material que se suba a la plataforma o se imprima.

## Estructura

```
05-entregables/
├── README.md                 # este archivo
├── informe-final/            # informe consolidado del proyecto
├── entregas-parciales/       # trabajos por unidad o fecha de entrega
└── presentaciones/           # diapositivas o material de defensa
```

## Reglas

- Cada entregable se arma con la plantilla `docs/plantillas/plantilla-entregable.md`.
- Los diagramas se referencian con imagen + link al fuente `.drawio` (ver
  `docs/plantillas/plantilla-diagrama-drawio.md`), nunca solo el link.
- Antes de entregar, verificar la trazabilidad completa: RF → UC → entidades →
  diagramas de interacción.
- Mantener el índice de este README actualizado con el estado de cada entregable.

## Checklist de salida

- [ ] Todos los diagramas del informe existen en `diagramas/exportaciones/`.
- [ ] Nomenclatura consistente (RF-XX, UC-XX) en todo el documento.
- [ ] Glosario incluido o referenciado.
- [ ] Supuestos revisados y validados con el equipo/profesor.
- [ ] Última actualización de la fecha del documento.
